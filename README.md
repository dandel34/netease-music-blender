# 网易云音乐 · Blender 内置播放插件

**在 Blender 里登录网易云、看自己的歌单（含「我喜欢的音乐」）、刷「每日推荐」和「私人雷达」，并且直接播放——不用切窗口，不用外部播放器。**

面板位置：**3D 视图 → 侧栏（N 键）→「网易云音乐」**

---

## 一、功能一览

| 需求 | 实现 |
| --- | --- |
| 功能面板 | 3D 视图侧栏独立分类「网易云音乐」，四个选项卡：账号 / 播放 / 歌单 / 推荐 |
| 登录账号 | **Cookie 导入**（唯一登录方式，任何网络环境下都可用） |
| 查看自己的歌单 | 「我的歌单」列表（含收藏歌单），**「我喜欢的音乐」自动置顶并配独立按钮** |
| **加入我喜欢的音乐** | 列表每行的 **♥** 一键加入/移出；播放页有「加入我喜欢的音乐」按钮；登录后自动同步全量 ♥ 标记 |
| 每日推荐 | 一键拉取，未登录时也能拿到 30 首通用推荐 |
| 私人雷达 | 自动定位「私人雷达」歌单并加载；找不到时可用歌单 ID 手动指定 |
| 音乐播放 | Blender 自带 `aud` 模块在**进程内**播放：播放/暂停/停止、上一首/下一首、进度条拖动、±10 秒、音量、单曲/列表循环、自动下一首 |
| 其它 | 播放队列、歌词、音质选择与自动降级、音频缓存、接口自检、一键清缓存 |

## 二、安装

### 方式 A（推荐）：安装扩展包

1. 打开 Blender → **编辑 → 偏好设置 → 插件**；
2. 右上角下拉箭头 → **从磁盘安装**；
3. 选择 `dist/netease_music-1.0.0.zip`（也可以从 Releases 页面下载）；
4. 在列表里勾选 **NetEase Cloud Music**（搜 `netease` 或 `网易云`）。

适用 Blender 4.2 ～ 5.2（扩展包格式）；3.6 ～ 4.1 请用方式 B。

### 方式 B：拷贝源码目录

把 `netease_music/` 整个文件夹拷到用户插件目录后重启 Blender：

```
%APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\netease_music\
```

然后在偏好设置的插件列表里勾选启用。

### 仓库结构

```
netease_music/     插件本体（11 个模块，注册入口 __init__.py + 扩展 manifest）
dist/              已打包好的安装包（改源码后请重新打包，见 tools/README.md）
tools/             打包与测试脚本（不影响插件运行）
.github/workflows/ CI（语法 / 自检 / 离线单测 / 打包一致性）与 Release（打 tag 自动发安装包）
```

## 三、60 秒上手

1. **登录**：侧栏 →「网易云音乐」→「账号」页 → 按面板上的 4 步导入 Cookie（见下方“登录方式”）。
2. **刷歌单**：「歌单」页 →「刷新我的歌单」→ 点列表里的歌单（或点「我喜欢的音乐」）。
3. **听歌**：列表里点某一行左边的 **▶** 直接播；或选中后点「播放选中」/「播放全部」/「随机播放」。
4. **收藏**：列表里点某一行左边的 **♥** 即加入「我喜欢的音乐」，再点一次取消。
5. **每日推荐 / 私人雷达**：「推荐」页两个按钮，点完列表就出现在下方。

播放进度、音量、队列在「播放」页；第一次播放会先把音频下载到缓存目录（之后秒播）。

## 四、登录方式：只用 Cookie

登录方式**只有 Cookie 导入**这一种（已按你的要求移除二维码与手机号登录），原因也很直接：

- 二维码登录走网页接口 `weapi`，在部分网络下会被网易云边缘节点**静默拒绝**（HTTP 200、响应体为空），成功率不可控；
- 手机号登录会被网易云对数据中心/代理 IP 的风控拦下（返回“当前登录存在安全风险”）；
- **Cookie 导入不发任何登录请求**，只是复用浏览器里已经登录好的凭据，任何网络环境下都能用。

### 步骤

1. 点面板里的「打开登录页」，在浏览器登录 <https://music.163.com>；
2. 按 `F12` → **应用 / Application → Cookies → https://music.163.com**；
3. 复制成 `MUSIC_U=xxx; __csrf=yyy; ...` 这样一整串（至少要含 `MUSIC_U`）；
4. 回到面板：点「从剪贴板粘贴」（或手动粘贴到输入框）→ **「使用 Cookie 登录」**。

插件会校验并把昵称、用户 ID、会员状态显示在面板上。Cookie 存在 Blender 用户偏好里，重启免登录；不想保存可以在偏好设置里关掉「记住登录状态」，或随时点「退出登录」清空。

> 登录成功后，歌单、每日推荐、私人雷达、♥ 收藏都会变成**你账号的数据**。

## 五、歌单 / 我喜欢的音乐 / 每日推荐 / 私人雷达

### 我喜欢的音乐（含收藏功能）

- 「歌单」页里带 **♥** 标记的就是它（`specialType == 5`），永远排在第一行；
- 「我喜欢的音乐」按钮一键打开，不用在列表里找；
- **收藏/取消收藏**：
  - 歌曲列表里每行左边的 **♥** 按钮：点一下加入「我喜欢的音乐」，已收藏的显示实心心形，再点一次取消；
  - 「播放」页正在播放的歌右上角也有 ♥，另有整行文字按钮「加入我喜欢的音乐」；
  - 列表下方还有「加入我喜欢的音乐」/「取消喜欢」按钮作用于选中的那一首；
  - 登录、刷新歌单时会自动同步一次你全部喜欢的歌曲 ID，因此列表里已收藏的歌**一打开就是实心 ♥**；
  - 同步状态显示在「账号」页（例如“已同步 1024 首”），也可以手动点「同步」重新拉取。
- 收藏接口优先用官方的 `/api/song/like`；如果这条路径在你的链路上不存在，会自动改用「往我喜欢的音乐歌单里加歌」的备用接口，状态栏会写明实际走了哪条（“喜欢接口”/“歌单接口（备用）”）。
- 大歌单（几千首）接口一次只给前若干首：默认先加载 300 首，需要更多就点 **「补齐全部歌曲」**。

### 每日推荐

- 接口 `/api/v3/discovery/recommend/songs`，通常 30 首，每天更新；
- **未登录也能用**（拿到的是通用推荐），登录后才是你自己的私人推荐；
- 列表下方「播放全部」即可整张列表循环播放。

### 私人雷达

网易云没有单独的“私人雷达”接口——它是首页推荐流里的**影子歌单**，需要登录后才会出现。所以插件按可靠性依次尝试三种来源：

1. **我的歌单**里名字含「私人雷达」/「雷达」的歌单；
2. **首页推荐流**（`/api/homepage/block/page`）里按标题找到它，取出歌单 ID；
3. **每日推荐歌单**（`/api/v1/discovery/recommend/resource`）。

三条都失败时，会给出可读的提示；你可以在 **偏好设置 → 私人雷达歌单 ID** 里手动填歌单 ID（歌单网页链接里 `id=` 后面那串数字），之后「私人雷达」按钮会直接用它。

定位逻辑有离线单元测试覆盖（伪造首页数据、逐一伪造三条数据源失败），见 `tools/test_netease_offline.py`。

## 六、播放相关

- **播放引擎**：Blender 自带的 `aud`（audaspace）模块，音频在 Blender 进程内播放，不调用任何外部程序。
- **歌词**：「播放」页点歌词右边的刷新按钮，前 14 行直接显示在面板里。
- **音质**：偏好设置里选（标准 128k / 较高 192k / 极高 320k / 无损 / Hi-Res）。请求的音质拿不到时自动往下逐级降级，实际拿到的音质会显示在「播放」页。
- **缓存**：默认在系统临时目录下的 `blender_netease_music/`，可在偏好设置里改。面板底部实时显示缓存大小，旁边可一键「打开缓存目录」/「清空缓存」。已缓存的歌再次播放**不再下载**。
- **循环与自动下一首**：不循环 / 单曲循环 / 列表循环；一首播完自动取下一首的直链并播放（已在真机验证）。
- **VIP / 无版权歌曲**：接口会返回「没有可用播放地址」，面板会显示原始接口码（例如 `-110`、`fee=1`）。这取决于你的账号权益和歌曲版权，插件无法绕过。

## 八、实现要点（给想改代码的人）

```
netease_music/
├── __init__.py     注册/注销、主循环定时器（只有它和 Blender 强相关）
├── crypto.py       纯标准库 AES-128（CBC/ECB）+ RSA + weapi/eapi/linuxapi 参数构造
├── api.py          三套协议的自动降级客户端 + 所有业务接口 + 数据标准化 + 收藏（含备用通道）
├── runtime.py      会话单例、播放状态机、队列、登录校验、♥ 缓存、私人雷达定位、tick 主循环
├── jobs.py         后台线程 + 主线程回收（所有网络请求都不阻塞界面）
├── player.py       aud 播放引擎 + 下载缓存
├── props.py        全部 RNA 属性（场景状态、歌曲/歌单列表项、♥ 标记）
├── ops.py          31 个操作符（Cookie 登录、加载、♥ 收藏、播放控制、自检…）
├── ui.py           侧栏面板 + 两个 UIList（每行带 ▶ 与 ♥）
└── preferences.py  插件偏好设置
```

几个关键设计：

1. **三套协议自动降级**。网易云同一功能在不同链路下可用性不同（实测：本机 `eapi` 与普通 `/api` 可用，`weapi` 被边缘节点静默拒绝）。`api.NeteaseClient` 会记录每条链路的失败次数，动态把它排到后面，并在“空响应 / 接口未找到”时自动换下一条链路，出错信息里会写明每条链路的真实返回。
2. **纯 Python 加密**。Blender 的解释器里没有 `pycryptodome`，所以 AES-128 是自己实现的（S 盒由有限域运算生成，避免手抄 256 项表出错），RSA 模数直接从官方公钥 PEM 解析，**不手抄常量**。用 FIPS-197 / NIST SP 800-38A 官方向量做自检。
3. **界面永不卡顿**。所有请求都在子线程，结果由 0.5 秒一次的主线程定时器回收后再写 RNA。
4. **aud 的两个坑（已实测并绕开）**：`Sound.length` 是**采样帧数**（要除以 `specs[0]` 才是秒）；`Sound.file(path, True)`（cached）对 mp3/m4a 会报 “couldn't be read with any installed file reader”，因此默认走流式读取 `Sound.file(path)`。
5. **ID 全部用字符串**。网易云歌曲 ID 超出 Blender `IntProperty` 的 32 位范围。

## 九、自检与排错

面板底部「运行自检」按钮（偏好设置里也有）会输出：

- 加密实现是否与官方向量一致；
- `aud` 模块是否可用；
- 登录状态 / 每日推荐 / 歌单详情是否通，以及**最近每次请求命中了哪种协议、返回什么码**。

常见现象：

| 现象 | 原因与处理 |
| --- | --- |
| 「三种接口都无法访问」 | 出口网络/代理限制，试试偏好设置里手动指定协议，或加 RealIP |
| 「需要登录后才能使用该功能」 | 该接口要求登录，先在「账号」页用 Cookie 登录 |
| 点了 ♥ 提示“请先登录” | 收藏属于账号操作，Cookie 登录后才可用 |
| 「这首歌没有可用的播放地址」 | 无版权 / 需要 VIP / 已下架 |
| 同时播放动画时音频互相干扰 | 关掉 Blender 场景音频（输出属性里的音量）或暂停音乐 |
